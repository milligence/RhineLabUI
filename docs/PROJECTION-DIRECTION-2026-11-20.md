# 投影演出重构：实体、边界与连续镜头

本轮依据用户对上一版的直接反馈重新设计演出。现有版本的光源缺少实体对应，体积过于朦胧，边界不完整，文字直到推进才显现，入口又串联了两次镜头启动。本轮先确定以下演出关系，再实现与逐帧打磨。

## 画面命题

同一画面必须能够看懂：右上角的矩形玻璃投影口从档案中出光，四棱光束抵达一个闭合的矩形薄片，真实档案信息在薄片内部逐次生成，镜头最后进入这幅已经形成的影像。

保留原实体的竖直抽取、材质、阵列波浪与同源相机。档案不作横向或向前的补偿移动。玻璃口采用已有 Blender 资产的闭合倒角几何与材质系统，在模型局部组合成正式部件；不另画屏幕硬件图标。

## 分镜与观察条件

以下为抽取取得净空后的目标节奏，最终秒数按真实连续画面校准。

| 段落 | 目标时段 | 画面与行动 |
| --- | --- | --- |
| 接续抽取 | 0–0.4 s | 从当前已绘制姿态接续。玻璃口的暗腔、边框与厚度已经存在，内部光开始积蓄。 |
| 光束展开 | 0.4–1.1 s | 从整个矩形口径扩展至右侧目标面。有限的软边保留四棱光锥的可辨形状。 |
| 建立边界 | 1.1–1.75 s | 近角先凝结，两条边传播，远角连接；四边闭合后再形成主要内容。 |
| 形成信息 | 1.8–3.0 s | 标题与主干进入，节点、分支及标签沿实际成像前沿逐步建立；已生成区域保持清晰。 |
| 共同呈现 | 3.0–3.65 s | 载体、玻璃口、光锥、闭合框与可识别内容共同呈现。相机只有低速漂移，无第二次起步。 |
| 接近阅读 | 3.65–6.1 s | 同一镜头连续归正与推进；光束先减弱，玻璃微小外沿随推进移至画幅外，标题和主图不二次出现。 |
| 稳定交接 | 最后约 0.5 s | 到达与最终 DOM 完全一致的位置，瞬态光效退出，工具进入并开放输入。 |

横屏目标构图：实体主体留在左侧约三分之一画幅，接收框占右侧约45–48%宽，源口与接收框之间有净空。框内标题、编号、主图在推进前已经可识别。竖屏以同一物理投影口为源，改用上下空间安排，不跳换发射角。

## 实现合同

- 实体口返回中心、矩形四角与原档案轮廓，坐标来自实际模型和已绘制相机。
- `CarrierFlight` 保留中途反向时的位置、速度与加速度接续；相机路径与光学节拍分开。
- 已呈现帧同时提供实际光学相位与相机姿态，DOM、出光口与光学层使用同一个已呈现状态。
- 光源、光束、薄片、边界、内容和工具使用独立通道。光束退场不能清除仍需存在的边界。
- 标题和内容属于同一个投影平面。成像清晰度由信息形成程度控制，不能再依赖镜头靠近才开放文字。
- 相机与投影面在同一个固定世界基准中计算；入口允许独立、有限的惯性接续，不能让普通读取镜头的残余阻尼拖动整张投影面。
- 渐进显影作用于真实内容，保持确定性和反向一致性。光学装饰只出现在实际显影前沿附近。
- 稳定阅读清除瞬态遮罩，关闭释放资源；减少动态直接到达明确终态。

## 三个视觉关卡

1. 光束抵达时，不读说明也能辨认实体矩形口、四棱光束和目标框。
2. 形成完毕时，能在同一画面认出源、框、标题与主图，不能只看见空白薄片或零散节点。
3. 推进中段能确认正在靠近刚才那一幅画面，标题、连线和边界保持连续的位置关系。

视觉核查优先使用真实 `ArchiveScene`、原 GLB 和生产组件。标定页保留为几何及光学定位工具，不能代替实体材质、遮挡与整段镜头的验收。每次调整记录实际截图与连续观察结论。
