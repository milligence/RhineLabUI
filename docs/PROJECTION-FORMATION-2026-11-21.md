# 完整演化树的投影成像精修

## 范围

用户于 2026-11-21 明确：现有演化树是好的方向，需要精修的是投影过场中框内的呈现。此次实现保留演化树、节点、关系、主线、阅读正文与现有操作。前一轮设计小样中将研究树降为附件的建议不作为本轮实施方向。

基线：`ae0458c668d6a9ed0cc5803720b9428c564c4ae5`。

## 成像

原实现按节点横向位置安排进入，部分标签与上下文共享曝光窗口。新的 `research-formation.ts` 根据真实连接和实测 SVG 弧长安排传播：主干在每个分叉处先行，局部分支随后接续；合流等待前向依赖，闭环和孤立节点也完整保留。整个调度是无状态函数，正放、反放和同一进度的重访得到相同结果。

路径上的光点、短尾与细粒来自同一条实际 SVG 曲线。弧长坐标在准备阶段缓存，播放时不逐帧采样新随机噪声，也不把整页转成位图。已经形成的线条留在原位。节点从入线方向描出轮廓，中心随后稳定，取消原来核心的突然放大。

完整图形始终是同一份 DOM/SVG；完成时移除临时路径遮罩，恢复原有实线、虚线、状态与选择样式。

## 文字与取景

结构形成和文字可读性使用不同通道。结构按光学相位形成；身份、节点名称、阶段说明、正文与控制随实际已呈现相机的接近进入。在相机尚未移动的形成和悬停阶段，完整树可以出现，正文和界面文字保持隐藏。

文字不再按整块界面进行横向擦出。节点名称的透明度放在内部 ink span 上，保留外层已有的碰撞隐藏、选中与聚焦规则。过场期间关闭独立 CSS transition，避免每帧曝光后又出现一次滞后的缓动。

较矮的桌面视口在悬停时使用暂时的全树取景，利用尚未被阅读界面占用的空间。镜头靠近后连续回到用户原有的图位置和缩放。节点坐标、保存的地图状态、完整阅读布局不因此改变。移动端与已聚焦阅读仍使用原有取景。

浏览器检查发现原有演化树样式覆盖了投影线宽补偿，SVG 的 non-scaling-stroke 也没有抵消外层地图与投影平面的 CSS 缩放。此次将补偿限定于过场总览，按实际显示比例维持主干约 0.9px、支线约 0.55px 的细线，再随阅读接近退回原样；主干、支线、合流各自在阅读端点精确回到原线宽，颜色与状态语义沿用原样。

## 时间与状态

总进入时长仍为 6800ms，镜头在 4200ms 开始接近，返回基准仍为 2400ms。结构的线性形成区间扩展为 1700–4000ms；局部轮廓与光点自行缓动，整图不重复套用总体缓动。

阅读通道使用当前已经画出的 `f.camera`，继续遵守实体场景和 DOM 的同帧采样。关闭时冻结内部研究回放和未完成的地图聚焦，保留当时画面；中途重新接入后恢复。关闭期间不覆盖已保存的阅读位置。转屏或尺寸变化建立的新目标取代旧视口目标。

## 复现与验收

```bash
npm run check:projection
npm run check:projection-ui-state
npm run check:carrier-optics
npm run check:optical
npm run build
node scripts/review-projection-cinematic.mjs --inline-fonts --compress --output .tools/formation-review
```

动态审片复用正式 `ProjectionViewer`、`ResearchProjection`、`CarrierFlight`、CSS 和 Canvas 光学层。公开合成样本包含 36 节点、39 条关系、23 步主线及长正文；它与私人档案的内容、具体布局和逐节点连接不同。

验收证据见 `verification/projection-formation-2026-11/`。状态与几何检查、浏览器画面检查分别记录。审片的标定光源用于隔离检查框内成像，不代表真实档案实体；完整 ArchiveScene 的 WebGL 画面和实际设备性能不由此推定。
